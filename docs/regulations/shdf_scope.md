# 扫黄打非平台受理范围要点(本地检索语料)

> 依据 docs/portal_shdf_notes.md(A14 只读调研)整理:全国"扫黄打非"工作小组
> 办公室主办;主站 www.shdf.gov.cn 为导航入口,实际在线举报表单在
> bzpt.shdf.gov.cn 子域(JS 渲染的单页应用)。本文件只记录受理范围标题与
> 适用方向,平台公告与受理口径以官方页面为准。

## 淫秽色情信息举报

互联网和手机媒体淫秽色情信息举报是该平台的核心受理范围。适用要点:传播淫秽
色情违法犯罪信息的站点,除 12377 外亦可由此平台反映;平台鼓励实名举报,举报
信息依法受保护。项目内固定类目文案"淫秽色情类"未经实地核验,以门户实际下拉
文案为准。

## 非法与违禁出版物

受理非法和违禁出版传播、侵权盗版、新闻出版单位及个人违法违规活动的举报。
适用要点:涉出版物盗版、违禁书刊及电子出版物传播的场景优先走此渠道;
具体范围以平台公告口径为准。

## 护苗专项行动相关

"护苗"行动聚焦涉未成年人有害出版物及信息治理。适用要点:涉未成年人有害
内容、少儿类非法出版物线索可在此反映;涉及儿童色情的举报同时适用 12377
色情类下的儿童色情危害小类,两渠道以官方指引为准。

## 备用举报渠道

举报电话 12390(另 010-65212870 / 010-65212787),举报邮箱 shdf@shdf.gov.cn。
适用要点:表单渠道受阻时的人工备用方式;拨打与发送由人工完成,工具不自动外呼。
